# The Gloomy Artist

A small solo game jam project built with Godot and GDScript.

Play as a gloomy artist determined to remove colour from a local mall. Paint as much as possible within 30 seconds while a janitor cleans up your work.

## Play

[Play in your browser on itch.io](https://cloudy-da.itch.io/the-gloomy-artist)

## Controls

- **WASD:** Move
- **Left mouse button:** Paint

## Features

- Painting mechanic that changes the environment
- A janitor that reverses your progress
- A 30-second time limit

## Development

**Role:** Solo developer  
**Engine:** Godot  
**Language:** GDScript  
**Platform:** Web browser

This repository contains the source project for the game jam release.

## Project Structure

- `Assets/` — Game assets
- `Scenes/` — Godot scenes
- `Scripts/` — Gameplay scripts
- `project.godot` — Godot project configuration
